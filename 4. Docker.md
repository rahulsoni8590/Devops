# Docker:

## Docker key components:
1. Images / Docker-images
2. Containers
3. DockerFile
4. Docker Engine/ Docker-server / Docker-daemon
5. Docker hub

1. Images = Is the snapshot of current state of a the machine.
2. Containers = It is formmed using the image which has the complete folderstructure,app dependency,nodejs app, and every thing which is required to run the application
3. Dockerhub = It a git like remote repository system which save the images remotely.
4. DockerFile = It a file which generate the image. It is configuration file or procedural file which tell what command should be run first, like in a chronological manner
5. Docker Engine/ Docker-server / Docker-daemon = In docker client and server are on the same machine unlike webapp.

## Docker Architecture
- Docker Client / Docker CLI = It is used to run the docker container.
- Docker Daemon/server = create the container take command from docker client
- Docker containers
- Docker Images
- Docker Registry is like git is to github = eg dockerhub (remote registry) , local registry also exist.
- Dockerfile
- Docker Networking
- Docker Volumes = It is like  harddisk of machine, incase machine misbehave harddisk data is save and portable.

# 
- docker -v = to check version

- docker info = infomation of all thing above and lot more.

- docker build -t first-image . = it tell docker to build an image with tag as first-image and dot means in the curret directory look for Dockerfile.
    - -t is used to name the image other will have remember it by id which is difficult.
    - as it can work with [docker build .] also.

- docker images = to see the images built.

- docker build -t first-image:1.0 -f Newimage . = here NewImage is the docker file name it will look for that file name by default. so without tagversion it will build the image with tag as latest.

- 3 - 4 character of image-id is unique so instead of using whole we can use only 3-4 chars.

- docker inspect image-id = look RootFS >> Layers = SHA256 == so if there are more the one layers that means there is another dockerfile create so two layers will be there.

- docker run ImageName:version = run the docker image in background and brought it down

- docker run -itd ImageName:version = run the docker image in detached mode in background >> its output is id

- docker run -it ImageName:version = run the docker image and give a cli/shell to interact with it [it=interactive-tty] so takes you inside the container.
    - inside shell run = uname [to get the FROM] and exit to comeout of shell.

- docker ps = list of running container
- docker ps -a = list of container running/stopped
- docker ps -q = to get id of all running container
- docker ps -a -q = to get id of all running/stopped container
- docker stop $(docker ps -q) = stop all running container
- docker start $(docker ps -q) = to start all containers
